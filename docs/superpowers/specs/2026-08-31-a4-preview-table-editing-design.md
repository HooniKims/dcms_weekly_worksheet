# A4 미리보기와 표 편집 설계

작성일: 2026-08-31

## 목표

관리자가 편집 화면에서 `A4 인쇄`를 눌렀을 때 곧바로 시스템 인쇄 창으로 넘어가지 않고, 현재 선택한 주차의 실제 A4 결과를 먼저 확인할 수 있게 한다. 편집기의 표는 고정된 2행 2열 삽입에서 벗어나 원하는 크기로 만들고, 만든 뒤에도 선택한 셀을 기준으로 행과 열을 쉽게 추가하거나 삭제할 수 있게 한다.

## 범위

- 관리자에게만 기존과 동일하게 A4 기능을 노출한다.
- 현재 선택 주차의 저장된 수합 결과를 A4 미리보기에 표시한다.
- 미리보기에서 `인쇄하기`와 `닫기`를 제공한다.
- 인쇄 상단 여백을 기존 0.10in보다 정확히 2mm 늘린다.
- 표 삽입 시 1×1부터 10×10까지 행과 열을 선택할 수 있게 한다.
- 삽입된 표의 셀을 클릭하면 선택 셀을 기준으로 행·열 추가 및 삭제 도구를 표시한다.
- 저장, 검색, 재사용, 기존 주간표 렌더링과 PDF 레이아웃은 그대로 유지한다.

## A4 미리보기 흐름

1. 관리자가 편집 화면에서 `A4 인쇄`를 누른다.
2. 현재 선택 주차의 `ReportView`를 담은 모달이 열린다.
3. 모달 상단에는 주차를 확인할 수 있는 제목과 `닫기` 버튼을 둔다.
4. 모달 하단에는 기본 강조 동작인 `인쇄하기`를 둔다.
5. `인쇄하기`를 누르면 모달의 도구 영역은 숨기고 A4 보고서만 시스템 인쇄 대상으로 전달한다.
6. 인쇄를 취소하거나 완료해도 미리보기는 유지되어 다시 확인하거나 닫을 수 있다.

미리보기는 저장된 수합 결과를 기준으로 한다. 현재 편집 중이지만 아직 저장하지 않은 초안은 포함하지 않으며, 편집 화면의 기존 저장 안내 문구로 이 규칙을 유지한다.

## 미리보기 레이아웃

- 기존 대화상자 표면과 포커스 스타일을 재사용하되, A4 문서가 들어갈 수 있도록 별도의 넓은 최대 폭을 사용한다.
- 보고서는 기존 66:660 열 비율과 인쇄용 글꼴 크기를 유지한다.
- 좁은 화면에서는 문서 전체를 비례 축소하고 모달 자체가 페이지 폭을 넓히지 않게 한다.
- 모달을 닫으면 `A4 인쇄` 버튼으로 포커스를 돌려보낸다.
- `Escape`와 `닫기` 버튼 모두 동일하게 모달을 닫는다.

## 표 삽입 흐름

1. 사용자가 서식 도구막대의 `표 삽입`을 누른다.
2. 도구막대 아래에 작은 표 설정 팝오버를 연다.
3. 행과 열은 각각 큰 `−`와 `+` 버튼으로 조절한다.
4. 중앙에 `3행 × 4열`처럼 현재 크기를 즉시 표시한다.
5. 기본값은 2행 2열이며, 허용 범위는 각 1~10이다.
6. `표 삽입`을 누르면 현재 커서 위치에 선택한 크기의 표와 뒤쪽 빈 문단을 만든다.
7. 취소하거나 바깥을 누르면 편집 내용을 바꾸지 않고 팝오버를 닫는다.

행·열 버튼은 비활성 상태를 명확히 표시한다. 1에서 감소하거나 10에서 증가할 수 없다.

## 삽입 후 표 편집 흐름

사용자가 편집기 안의 표 셀을 클릭하면 그 셀을 활성 셀로 저장하고, 서식 도구막대에 다음 네 개의 한글 버튼을 표시한다.

- `아래에 행 추가`
- `현재 행 삭제`
- `오른쪽에 열 추가`
- `현재 열 삭제`

행 추가는 활성 셀의 행 바로 아래에 같은 열 개수의 빈 셀을 만든다. 열 추가는 모든 행의 활성 열 바로 오른쪽에 빈 셀을 하나씩 만든다. 삭제는 활성 행 전체 또는 모든 행의 활성 열을 제거한다. 마지막 한 행 또는 마지막 한 열은 삭제할 수 없으며 해당 버튼을 비활성화한다. 조작 후에는 새로 생긴 인접 셀 또는 남아 있는 가장 가까운 셀을 활성 상태로 유지해 연속 작업이 가능하게 한다.

편집기 바깥을 클릭하거나 다른 일반 문단에 커서를 두면 표 편집 도구를 숨긴다. 도구 버튼을 누를 때 브라우저 선택 영역이 사라져도, 마지막으로 클릭한 실제 셀을 기준으로 작업한다.

## 데이터와 보안

- 표는 기존과 같은 `table`, `tbody`, `tr`, `td` 구조로 저장한다.
- 새 메타데이터나 데이터베이스 필드를 추가하지 않는다.
- 기존 HTML 정제 규칙을 통과한 구조만 저장한다.
- 내용 변경 후에는 기존과 동일하게 편집 상태를 `저장 전 변경사항`으로 표시하며 사용자가 저장 버튼을 눌러야 반영된다.

## 인쇄 여백

기존 상단 여백 0.10in은 2.54mm이므로 새 상단 여백은 4.54mm로 설정한다. 좌우와 하단 여백은 변경하지 않는다. 실제 Chrome A4 출력에서 제목 상단이 잘리지 않고, 한 페이지 출력과 기존 표 폭이 유지되는지 확인한다.

## 오류 및 경계 조건

- 선택한 셀이 이미 제거되었거나 편집기에서 분리된 경우 표 조작을 수행하지 않고 도구를 숨긴다.
- `rowspan` 또는 `colspan`이 포함된 이전 자료는 그대로 표시하고 저장할 수 있다. 이번 행·열 조작은 일반 직사각형 표에서만 활성화하며 병합 셀 표에서는 조작 버튼을 비활성화한다.
- 인쇄 API를 사용할 수 없는 환경에서는 미리보기는 유지하고 인쇄 호출만 수행하지 않는다.

## 접근성

- A4 미리보기는 이름이 있는 모달 대화상자로 노출한다.
- 표 크기 조절, 삽입, 행·열 조작 버튼에는 동작을 완전히 설명하는 한글 접근성 이름을 사용한다.
- 키보드 포커스 표시와 최소 조작 크기는 기존 디자인 토큰을 따른다.
- 표 설정의 현재 크기는 화면과 보조 기술에서 모두 갱신 내용을 알 수 있게 한다.

## 검증

- A4 버튼이 인쇄를 직접 호출하지 않고 미리보기를 여는 테스트
- 미리보기의 `인쇄하기`, `닫기`, Escape 동작 테스트
- 관리자 인증 전에는 A4 기능이 계속 노출되지 않는 회귀 테스트
- 1×1, 기본 2×2, 최대 10×10 삽입 테스트
- 활성 셀 기준 행·열 추가 및 삭제 테스트
- 마지막 행·열 삭제 방지와 병합 셀 비활성화 테스트
- 저장 후 `ReportView`에서 변경된 표가 동일하게 렌더링되는 테스트
- 실제 Chrome의 375px, 768px, 1280px 미리보기와 A4 PDF 시각 검증
- A4 PDF가 한 페이지이며 제목 상단과 우측 경계가 잘리지 않는지 확인
